# Kokuk

Hackathon project (Konkuk Ideathon). The problem statement/question is still being decided.

Repo: https://github.com/muhdhayyun/konkuk-ideathon

Stack: React + TypeScript (Vite), scaffolded blank — features TBD once the problem statement is chosen.

## Environment

Development will happen entirely in an online/cloud environment, not locally. Do not set up `.env` files or local secret management for this project.

## Working agreement

- After making changes to this project, commit and push them to `origin` without asking for confirmation first.
- Use clear, concise commit messages describing the change.
